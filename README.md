
# CSYE 6200 - Java Practice

## How to Clone and Run the Code

### 1. Clone the Repository

Open your terminal and run:

```bash
git clone https://github.com/CsyeInfoLab/CsyeInfoLab.git
```

Replace the URL with the repository link.

### 2. Open the Project

Navigate to the cloned repository:

```bash
cd CsyeInfoLab
```

Open the project in IntelliJ IDEA or VS Code.

### 3. Run the Java Program

Open the following file:

```text
src/edu/neu/csye6200/Driver.java
```

Run the `main` method.

### Expected Output

```text
Hello World
```

### 4. Make Changes

You can modify the code inside the `main` method and run the program to see the output.
